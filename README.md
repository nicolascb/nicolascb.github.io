# nicolascb.github.io

Blog pessoal construído com [Astro](https://astro.build) e o tema [Astro Palette](https://astro.build/themes/details/astro-palette/).

## Comandos

```bash
npm install
npm run dev     # servidor de desenvolvimento
npm run build   # build estático + índice de busca Pagefind
npm run preview # preview do build de produção
npm run check   # verificação de tipos
```

A busca utiliza o índice do Pagefind gerado em `dist/pagefind`; execute `npm run build` uma vez antes de testar a busca em desenvolvimento.
